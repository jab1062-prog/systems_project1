MANUAL TEST EXAMPLES

Place this manual-tests folder inside P2 beside words.c and Makefile.
Run the commands below from P2 after running make.
No test program or script is needed. These files are optional development
examples, separate from the minimal project ZIP.

1. Assignment example and final word without a newline

./words manual-tests/first.txt

Expected:
spam 2
bacon 1
eggs 1

2. Capitalization, punctuation, hyphens, and numbers

./words manual-tests/rules.txt

Expected:
foo 2
Foo 1
a 1
bar 1
don't 1
foo-bar 1
z 1

3. Combined counts across files

./words manual-tests/first.txt manual-tests/second.txt

Expected:
spam 3
bacon 1
eggs 1

4. Recursive directories, hidden entries, and default suffix

./words manual-tests/samples

Expected:
spam 2
eggs 1

5. Both suffix forms and explicitly named files

./words -s .md manual-tests/samples
./words -s.md manual-tests/samples
./words manual-tests/samples/other.md

Expected for each command:
bacon 1

6. Empty input

./words manual-tests/empty.txt

Expected: no output.

The hidden entries samples/.skip.txt and samples/.hidden/c.txt contain
"ignore". That word must not appear when traversing samples.
The input files deliberately have no trailing newline.
